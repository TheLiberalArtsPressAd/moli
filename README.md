# Crossgate Survivors 魔力寶貝幸存者

Unity C# 專案（Unity 2021.3.30f1），另外附一份純 HTML5 網頁版。

## 線上遊玩

**`https://theliberalartspressad.github.io/moli/`**

> 注意網址是 `the**liberal**artspressad`，少一個 `i` 就會變成 404。

- 網頁版就是根目錄的 `index.html` + `game.js`，不需要 Unity WebGL 建置，也不需要任何 Secrets。
- GitHub Pages 設定：`Settings > Pages` → `Deploy from a branch` → `main` / `/ (root)`。
- 只有一份網頁版程式碼（根目錄），沒有 `docs/` 副本，避免兩份不同步造成「卡片空白」。

## 檔案結構

| 路徑 | 用途 |
| --- | --- |
| `index.html` / `game.js` / `style.css` | 網頁版遊戲 |
| `audio.js` | 網頁版音樂／音效播放器（BGM 交叉淡入淡出、Web Audio 合成音效與地形環境音、靜音、音量記憶） |
| `art.js` | 網頁版美術層（俯視角、原版地圖 + 各關卡色調、角色、怪物、場景物件） |
| `web-assets/art/` | 網頁版使用的美術素材（由 `Tools/build-web-assets.ps1` 從 `Assets/` 產生） |
| `web-assets/monsters/` | 405 種原版怪物素材 × 6 種動作（待機／行走／攻擊／施法／受傷／死亡）＋攤平後的 `<state>_sheet.webp` |
| `web-assets/audio/` | 網頁版 BGM（3 首原版曲目）與升級／勝利／介面音效 |
| `Tools/build-web-assets.ps1` | 從專案原本的美術檔產生 `web-assets/art/` |
| `Tools/extract-cg-character.py` | 從原版客戶端 `Graphic*.bin` / `Anime*.bin` 解出角色圖檔（Python 版 CGTool） |
| `Tools/build-character-assets.py` | 產生劍士／弓箭手的 8 方向待機、行走、攻擊 sprite sheet |
| `Tools/build-monster-assets.py` | 掃描怪物素材資料夾，產生 `web-assets/monsters/` 與 `catalog.json`（可續傳，只補缺的動作） |
| `Tools/build-monster-sheets.py` | 把動畫 WebP 攤成橫向 sprite sheet（`<state>_sheet.webp`）並產生 `sheets.json`，讓 canvas 能逐格播放 |
| `Tools/build-levels.js` | 由怪物圖鑑自動產生 15 個地區關卡與霸主設計（含怪物技能、地區機制、精英怪與霸主第三階段） |
| `Tools/monster-preview.html` | 405 種怪物圖鑑（可切換 6 種動作） |
| `Tools/biome-preview.html` | 十五個關卡的景色預覽頁 |
| `admin.html` / `admin.js` | 網頁版數據後台（讀寫 `config/game_config.json`） |
| `config/game_config.json` | 網頁版與工具共用的設定檔 |
| `Assets/` / `Packages/` / `ProjectSettings/` | Unity 專案 |
| `godot/` | Godot 專案（手動 workflow 才會用到） |
| `Tools/MoliConfigEditor/` | 獨立 EXE 後台（dotnet build） |
| `Tools/serve-web.ps1` | 本機預覽用 |
| `Tools/legacy/` | 舊的一次性修補腳本，保留參考、不參與執行 |

## 本機預覽

```powershell
powershell -ExecutionPolicy Bypass -File Tools\serve-web.ps1
```

然後開 `http://localhost:8080/`，Ctrl+C 結束。直接雙擊 `index.html` 也可以玩（會用內建設定）。

> 瀏覽器會阻擋自動播放，第一次點擊畫面或按鍵後才會開始播放音樂。

## 修改網頁版之後

1. 改 `index.html` 內的 `?v=YYYYMMDD-n` 版本號（`style.css`、`game.js`、`admin.js` 都要），避免瀏覽器拿到舊快取。
2. `git add -A && git commit -m "..." && git push`
3. 等 GitHub Pages build 完成（約 30～60 秒）。

## 後台編輯系統

- **網頁後台**：`admin.html`（可下載 `game_config.json`，覆蓋後 push）
- **Unity 編輯器後台**：`Tools > Crossgate Survivors > 設定編輯器（後台）`
- **獨立 EXE 後台**：`Tools/MoliConfigEditor/`
- **JSON 設定**：`config/game_config.json`、`Assets/StreamingAssets/Config/`

- 視角是**俯視角**（和 Unity 版一樣），不是斜角。
- 每個關卡都用同一張原版地圖，加上不同色調分級與環境效果做出不同景色：
  森林、海島、樹海、洞窟、沙漠、雪山、火山、靈堂、海底。
- **怪物全部使用原版素材**：`web-assets/monsters/` 內含 405 種怪物、2,430 段動作，
  每種都有待機（idle）／行走（walk）／攻擊（attack）／施法（special）／受傷（hurt）／死亡（die），
  戰鬥中會依狀態播放；素材來自 `魔力寶貝怪物素材`，以無損動畫 WebP 轉檔（約 53 MB）。

  攤成橫向 sprite sheet，`art.js` 再依 `sheets.json` 的格數與每格毫秒自己切格。走路、攻擊、

  角色圖直接從客戶端 `Graphic*.bin` / `Anime*.bin` 解出，不是用舊的單張 GIF 改色。

  ```powershell
  python Tools\build-character-assets.py
  ```
- 重新產生怪物素材（換了素材資料夾之後，已存在的動作會跳過）：

  ```powershell
  python Tools\build-monster-assets.py
  python Tools\build-monster-sheets.py
  node Tools\build-levels.js
  ```

- 重新產生場景素材（換了 `Assets/` 裡的圖之後）：


## 角色魔法（MP／冷卻／自動施放）

- 每位角色開場有 **6 個魔法**，開場即擁有前 3 個，第 4～6 個依 `UnlockLevel` 解鎖（Lv.4／Lv.6）。
- 升級卡會出現 **32 種新魔法**（冰錐術、烈焰噴射、風暴之眼、毒爆術、暗影新星、聖光十字、
  雷神之怒、時空裂縫、流星雨、治癒之泉、荊棘領域、元素稜鏡、破空聖芒、霜華爆裂、星界墜落、
  元素風暴、裂地斬、追魂箭雨、聖域、天雷鎖、暗影分身、炎龍破、冰封絕境、萬劍歸宗，
  以及新增的劍刃風暴、黑洞引力、烈日審判、龍焰吐息、極光冰晶、連鎖雷神之怒、血月斬、星界裂隙），
  可自由學成，**魔法書上限 9 格**，讓每局的技能組合都不一樣。
- 魔法會**自動施放**（冷卻完成、MP 足夠、有合適目標時），也可以按鍵盤 `1`～`9` 手動施放。
- HUD 左下新增 **MP 條**與狀態列（護盾、緩速、持續回復、地區機制倒數）；技能列會顯示快捷鍵、
  MP 消耗、冷卻秒數與魔法階級 `R1`～`R5`，魔力不足時變紅、未解鎖時顯示 `Lv N`。
- MP 會隨時間自然回復，升級時上限提高；升級選項中會出現 **魔法精研**（傷害／效果 +18%、冷卻與消耗降低）、
  魔力、法術強度、冷卻與消耗相關強化。
- 升級時一次給 **4 張卡（2×2 排列）**，並保證至少兩張「魔法」或「能力」卡，不會只出現純數值卡。

| 不屈意志 | 生命低於 30% 時每秒回復生命 |

## 怪物技能與精英怪

- 怪物不再只會近戰：`config/game_config.json` 的 `Skills[]` 新增 `Kind: "e_*"`、`Side: "enemy"` 的技能，
  由 `Tools/build-levels.js` 依地區與體型自動分配（技能 ID 200–221）。
- **每隻小怪都至少帶一招有特效的攻擊技能**；若原始資料只有輔助技，會自動補上魔彈或扇形吐息。
- 怪物會**詠唱**（頭上顯示施法條、腳下元素法陣）後放出魔彈、毒霧、冰錐、落石、治療、狂暴、衝撞、雷擊、詛咒、
  骨矛、水彈、風刃、暗影彈、聖光、熔岩、冰霜新星、沙塵、靈魂吸收、屏障、孢子召喚、蛛網等招式。
- **原版動作狀態全數啟用**：待機 `idle`、行走 `walk`、攻擊 `attack`、施法 `special`、受傷 `hurt`、死亡 `die`。
  行走時有步伐起伏、攻擊有前衝、施法會浮起、受傷會抖動、死亡會完整播放後才淡出。
- **多種移動 AI**：直衝 `chaser`、蛇行 `zigzag`、繞行 `circler`、遠程游擊 `skirmisher`、
  支援 `support`、重裝 `brute`、蓄力衝鋒 `charger`；衝鋒前會停下並亮起警示圈。
- **多種近戰演出**：斬擊 `slash`、撕咬 `bite`、重砸 `slam`、突刺 `sting`、爪擊 `claw`，
  以及三段連擊 `combo`、遠距吐息 `spit`；近戰有起手動作與延遲命中，看到抬手可以走位躲開。
- 每一波會依關卡難度標記 **精英怪**（名稱前綴 `精英·`、金色光環、2.35 倍 HP、1.3 倍 ATK、
  額外技能、3.2 倍經驗）；後期關卡的精銳／親衛波精英數量更多。
- 霸主在血量低於 `Phase2At` 後進入狂暴，低於 `Phase3At` 後進入 **狂亂**：出招更快、彈幕更密，
  並追加地區招牌招式（`root`／`quake`／`frost`／`rain`／`spiral`／`beam`）。
- 小怪的治療不會再補到霸主身上，霸主自身治療也有 9 秒冷卻與 5% 上限，避免血量在高點反覆回滿、戰鬥卡死。

## 地圖互動物件

- 每關開場會在玩家四周散佈 **4 個互動物件**，戰鬥中地上也會定期補充；剩餘少於 3 個時會用光暈與提示音提醒玩家去尋找。
- 走過去就會自動觸發，不需要按鍵；用完後會淡出消失，不會留下空殼。
- 共 5 種，效果各自不同：

| 物件 | 效果 |
| --- | --- |
| 寶箱 | 噴出大量經驗球，並回復生命、魔力與終極技能充能 |
| 祈願神龕 | 回復 40% 生命、展開最大生命 20% 的護盾，並讓所有魔法冷卻歸零 |

| 營火 | 回復生命與魔力，並獲得每秒 +0.45 的生命回復 |

## 音樂與音效

- 主選單、第 1～5 關、第 6～10 關、第 11～15 關與霸主波使用不同 BGM，
  切換時會交叉淡入淡出，不會突然中斷。
- BGM 用 `<audio loop>` 播放原版 WAV，避免 MP3 編碼延遲造成迴圈接縫；
  音效則走 Web Audio，反應較即時。
- 主選單上方有 **音樂開關與音量滑桿**；遊戲中右上角 `♪` 按鈕或鍵盤 `M` 可快速靜音。
  音量與靜音狀態會存在 `localStorage`，下次開啟會沿用。
- 升級播放原版升級音效，破關播放勝利音效；為避免連續升級時聲音疊在一起，音效有最短間隔。
- **地形環境音**：森林蟲鳴、洞窟水滴、雪山風聲、火山低鳴、靈堂鬼火、海底氣泡、海岸浪聲、
  沙漠風沙等 9 種循環由 Web Audio 即時合成，會隨關卡切換，並混入隨機的環境事件音。
- 新增合成音效：霸主詠唱、神龕祈願、魔力結晶、營火、戰魂圖騰、怪物死亡（小怪／霸主分開）、
  新魔法施放（虛空、星辰、雷神、血月、星界）等。
- 素材來源：`Assets/Resources/Audio/bgm`、`Assets/Resources/Audio/se`，複製到 `web-assets/audio/`。

## 穩定性

- 敵人、彈幕、玩家射擊、地面區域、特效、浮動數字、發射器與霸主召喚都有上限
  （敵人 88、敵彈 280、射擊 220、區域 48、特效 240、浮動數字 80、發射器 16），
  避免後期關卡或長時間掛機把記憶體與畫面拖垮。
- 主迴圈與全域錯誤事件會攔截例外，並在畫面上顯示錯誤面板（含訊息與堆疊），
  不會再出現「畫面停住但沒有提示」的情況。


## 網頁版除錯參數

| 參數 | 作用 |
